# 🍦 Creamy Bliss — Ice Cream Website

Welcome to **Creamy Bliss**, a modern and visually appealing ice cream website designed to showcase delicious ice cream flavors through an elegant and user-friendly interface. The project focuses on attractive product presentation, a clean layout, and a delightful browsing experience.

🔗 **Live Demo:** [Creamy Bliss Website](https://creamybliss-eta.vercel.app/)

💻 **GitHub Repository:** [Creamy-Bliss](https://github.com/msaadatali677-hub/Creamy-Bliss)

## ✨ Features

- 🍨 Attractive ice cream website design
- 🎨 Modern **Neumorphism UI Design**
- 🍓 Beautiful ice cream product presentation
- 📱 Responsive layout for desktop, tablet, and mobile devices
- 🧭 Clean and user-friendly navigation
- 🌈 Soft colors and elegant visual elements
- ⚡ Smooth and engaging browsing experience
- 💻 Frontend-focused web development project

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, and visual effects
- **JavaScript** — Interactive functionality

*Note: The technology list reflects the intended frontend stack. Update it if your repository uses additional technologies.*

## 🎯 Project Purpose

The purpose of Creamy Bliss is to create a professional frontend website for an ice cream brand. It demonstrates modern web design principles, product-focused layouts, and the use of Neumorphism to create a soft, elegant user interface.

## 📂 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/msaadatali677-hub/Creamy-Bliss.git
   ```

2. Open the project folder:

   ```bash
   cd Creamy-Bliss
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
